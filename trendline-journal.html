HJ 추세선 거래 저널 템플릿 v1

이 페이지는 HJ 추세선 전략의 거래 후 복기, A+ 판정, fakeout 분석, 패스 기록을 남기기 위한 실전 저널 템플릿 도구임. 기준서 본문을 다시 읽는 공간이 아니라, 실제 거래와 패스 결정을 빠르게 복붙하고 누적 리뷰하기 위한 입력 도구 중심 페이지다.

이 페이지의 역할

실전 거래 결과, 패스 사유, 반복 실수를 같은 구조로 남겨 다음 트레이드 품질을 끌어올리는 기록용 문서.

기록 핵심

A+ 여부, fakeout 필터 적용, 리스크 품질, 늦은 진입 여부를 빠짐없이 체크하는 데 초점.

사용 환경

모바일 메모앱, 노션, 문서, 프린트, 캡처 어디에 붙여도 읽기 쉬운 다크 문서형 레이아웃.

기준서 / 체크리스트 / 저널 역할 구분

세 페이지는 중복 설명이 아니라 서로 다른 단계에서 사용하도록 분리했다.

3-Page Workflow

기준서 페이지

전략 철학, 운영 원칙, 리스크 기준, setup 해석 기준을 읽고 기준점을 맞추는 페이지.

체크리스트 페이지

진입 전 체크박스로 A+ 조건, 패스 조건, 위험 신호를 실시간으로 확인하는 페이지.

저널 페이지

거래 후 복기와 패스 로그를 남기고, 반복 실수와 fakeout 패턴을 누적 분석하는 페이지.

사용 방법 요약

복붙 속도와 사후 리뷰 효율을 우선한 실전 사용 흐름.

How to Use

1. 거래 직후 바로 복붙

실전 거래 기록 템플릿을 복붙한 뒤 기본 정보 → 셋업 → 진입 → 청산 → 평가 순서로 채운다.

2. 패스도 동일하게 기록

진입하지 않은 차트도 패스 기록 템플릿으로 남겨 A+ 미달 상황을 학습 데이터로 만든다.

3. 주간 리뷰에서 재사용

아래 리뷰 질문, 반복 실수 체크, 판정 기준 요약을 이용해 거래 품질을 일관되게 평가한다.

A+ / A / B / mediocre / 패스했어야 함 판정 기준 요약

상세 기준은 운영 기준서와 체크리스트를 따르되, 저널에서는 아래 요약 문구로 일관되게 점수화한다.

Rating Guide
A+

모든 핵심 조건이 정렬되고 브레이크 질, retest, 리스크, 타이밍이 매우 우수한 거래. 다시 와도 그대로 실행할 만한 수준.

A

전반적으로 좋고 규칙도 지켰지만 일부 요소가 A+만큼 선명하지 않은 거래. 충분히 실행 가능하나 개선 포인트가 남는다.

B

구조는 있었지만 한두 요소가 애매했던 거래. 결과와 무관하게 다음에는 더 선별해야 하는 수준.

mediocre

setup 질이 평범하거나 확신 근거가 부족했던 거래. 실행보다 패스가 더 적절했을 가능성이 높다.

패스했어야 함

늦은 진입, 과도한 손절, fakeout 위험, 세션 문제, 뉴스 위험 등으로 규칙상 거르면 좋았던 거래.

기준서는 원칙을 정하고, 체크리스트는 진입 전 품질을 거르고, 저널은 실제 행동과 패스 결정을 축적해 다음 거래의 기준 품질을 높인다.
