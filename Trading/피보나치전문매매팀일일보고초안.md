# Trading/피보나치전문매매팀일일보고초안

## 1) 팀 역할 한 줄 요약
피보나치 전문 매매팀은 **피보나치 되돌림을 활용해 추세 내 실전 진입 후보를 선별**하고, 진입/보류/제외 판단을 표준화해 본사 의사결정을 지원하는 팀이다.

---

## 2) 일일보고 표준 형식 (운영 매뉴얼)
아래 템플릿을 매일 같은 순서로 작성한다.

### 오늘 한 일
- 시장 스캔/차트 검토/후보 정리 등 **오늘 실제 수행한 작업** 요약
- 수치 중심으로 작성 (예: 관찰 종목 수, 분류 수)

### 현재 진행중
- 아직 판단이 끝나지 않은 종목/시나리오
- 추가 확인이 필요한 데이터/차트 조건

### 완료된 것
- 오늘 최종 확정한 판단과 산출물
- 체크리스트 완료 항목, 복기 완료 건

### 막힌 것 / 문제
- 데이터 누락, 기준 충돌, 팀 리소스 부족, 변동성 급증 등
- 문제의 영향 범위(어떤 판단이 지연되는지) 명시

### 다음 행동
- 다음 보고 전까지 할 구체 행동 3~5개
- 담당자/우선순위/마감 시각 포함 권장

### 연결된 Codex 작업
- 플레이북 업데이트
- 차트 예시 정리
- 체크리스트 개선
- 자동 분류/리포트 스크립트 개선

### 본사 판단 필요사항
- 팀 단독 결정이 어려운 이슈를 짧게 상신
- 예: 진입 기준 임시 완화 여부, 제외 기준 강화 여부, 리스크 한도 조정

---

## 3) 보고에 들어갈 핵심 내용 예시 (필수 지표)
매일 아래 항목을 숫자로 기록한다.

- 오늘 관찰한 종목 수: `__개`
- A급 / B급 / C급 분류 수: `A __개 / B __개 / C __개`
- 골드존 진입 후보 수: `__개`
- 실제 판단 수: `진입 __건 / 보류 __건 / 제외 __건`
- 실패 사례 복기 여부: `완료 / 미완료`
- 체크리스트 미충족 항목: `__건 (항목명: __)`

> 작성 원칙: **숫자 + 판단 + 다음 액션** 1줄 구조로 쓴다.

---

## 4) 샘플 일일보고 (복붙용)
아래 샘플을 그대로 복붙해서 날짜/숫자만 바꿔 사용한다.

```md
# 피보나치 전문 매매팀 일일보고
- 보고일: 2026-04-03
- 작성자: 홍길동

## 오늘 한 일
- 관찰 종목 42개 스캔 완료, A/B/C 분류 완료 (A 6, B 14, C 22)
- 골드존(0.5~0.618) 재진입 후보 7개 추출
- 후보 7개 중 진입/보류/제외 1차 판단 완료

## 현재 진행중
- A급 2개 종목: 거래량 확인 후 최종 진입 여부 확정 예정
- B급 3개 종목: 상위 타임프레임 추세 일치 여부 재검토 중

## 완료된 것
- 최종 판단: 진입 3건 / 보류 2건 / 제외 2건
- 실패 사례 1건 복기 완료 (손절 지연 원인 기록)
- 체크리스트 12개 중 10개 충족 확인

## 막힌 것 / 문제
- 1개 종목 데이터 지연으로 종가 기준 확인 불가
- 영향: 진입 1건 확정이 장 시작 전까지 지연될 가능성

## 다음 행동
- 08:40까지 데이터 재수집 후 해당 1개 종목 재평가 (담당: 김OO)
- 보류 2건에 대해 시가 갭 조건 추가 확인 (담당: 이OO)
- 실패 복기 내용을 플레이북 손절 섹션에 반영 (담당: 박OO)

## 연결된 Codex 작업
- 플레이북: 손절 지연 방지 규칙 1개 추가
- 차트 예시: A급 진입/제외 사례 각 1장 업데이트
- 체크리스트: "거래량 급감 예외" 항목 문구 수정

## 본사 판단 필요사항
- 변동성 확대 구간에서 A급 진입 기준(되돌림 허용폭) 임시 완화 여부 승인 요청
- 내일 1일 한정 종목당 최대 리스크 0.8% → 0.6% 하향 적용 승인 요청
```

---

## 운영 연결 가이드 (플레이북/차트/체크리스트)
- 본 문서의 `막힌 것 / 문제`는 **플레이북 개선 후보**로 즉시 이관
- `실패 사례 복기`는 **차트 예시 라이브러리**에 케이스 단위로 적재
- `체크리스트 미충족 항목`은 다음 영업일 체크리스트 개정 안건으로 자동 등록

짧게 쓰되, 본사가 바로 판단할 수 있도록 **수치·상태·요청**을 항상 함께 적는다.
