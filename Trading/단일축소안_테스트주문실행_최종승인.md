# 단일 축소안 테스트 주문 실행 최종 승인서 (v1)

- 문서 목적: 단일 축소안(1종목/1회/10만원/지정가) 테스트 주문의 **최종 실행 여부**를 고정하고, 실행 전후 통제 절차를 문서화한다.
- 작성일: 2026-04-25
- 적용 범위: 테스트 주문 1건(당일 1회)

---

## 1) 최종 판단 결과

### 최종 상태: **보류(재검토 필요)**

판단 근거:
1. 체크리스트 충족 증빙(최종 서명본/타임스탬프/증적 링크) 미첨부.
2. 실행 대상 1종목 코드와 지정가 산출 근거(호가 단위/슬리피지 허용범위) 미고정.
3. 수동 승인권자(1차/2차) 및 승인 로그 포맷 미확정.

> 원칙 적용: 체크리스트 미충족, 수동 승인 미완료 상태이므로 **실행 금지**.

---

## 2) 의사결정 레벨 정의 (승인/보류/차단/재검토)

- **승인(Go)**: 모든 사전 체크리스트 + 수동 승인 2인 완료 + 실행 파라미터 고정 완료.
- **보류(Hold)**: 필수 입력값 일부 누락. 보완 후 같은 영업일 내 재승인 가능.
- **차단(Block)**: 정책 위반 또는 리스크 한도 위반. 당일 실행 불가.
- **재검토(Review)**: 전략/시장상황 변화로 기준 자체 재평가 필요.

현재 상태는 **보류(재검토 동반)**로 분류한다.

---

## 3) 실행 조건 고정안 (승인 시에만 활성)

아래 항목이 모두 채워지고 승인 서명이 끝나기 전까지 주문 실행 금지.

- 종목 수: **1종목 고정**
- 주문 횟수: **1회 고정**
- 주문 금액: **100,000원 고정**
- 주문 방식: **지정가만 허용**
- 추가 진입/물타기/분할주문: **금지**
- 자동 재시도: **금지**

### 실행 파라미터 잠금 필드 (필수)
- 거래일: `YYYY-MM-DD`
- 종목명/종목코드: `________ / ________`
- 매수 지정가: `________원`
- 주문 유효시간: `HH:MM ~ HH:MM`
- 취소 조건 시각: `HH:MM`
- 비상 중단 트리거 담당자: `________`

---

## 4) 수동 승인 절차 (필수)

### 승인 게이트
1. **1차 승인(전략 담당)**: 체크리스트 충족 여부 확인 + 실행 파라미터 검증.
2. **2차 승인(리스크 담당)**: 금액/횟수/종목수/주문방식 정책 준수 확인.
3. **최종 실행자 확인**: 주문 직전 음성/메신저 재확인 후 실행.

### 승인 로그 템플릿
- 승인 시각:
- 승인자(1차):
- 승인자(2차):
- 실행자:
- 승인 문구: `"단일 축소안 테스트 주문 1종목/1회/10만원/지정가 조건으로 실행 승인"`
- 로그 위치(문서/채널 링크):

승인 로그 누락 시 즉시 **실행 금지**.

---

## 5) 주문 후 리포트 항목 (실행 시 필수)

주문 체결 후 30분 내 1차 리포트, 당일 종료 후 최종 리포트를 작성한다.

### 1차 리포트
- 주문 접수 시각 / 체결 시각
- 요청 가격 / 체결 가격 / 괴리(틱, %)
- 체결 수량 / 미체결 수량
- 실행 중 이상 징후 유무

### 최종 리포트
- 진입 근거 체크리스트 재대조 결과(충족/미충족)
- 손익 결과(원, %)
- 계획 대비 이탈 항목(있음/없음 + 상세)
- 재실행 권고: 승인 / 보류 / 차단 / 재검토
- 개선 액션 1~3개

---

## 6) 즉시 중단/재보류 조건

아래 중 1개라도 충족 시 즉시 중단하고 상태를 **재보류**로 전환.

1. 지정가 외 주문이 발생했거나 발생 시도가 감지됨.
2. 10만원 초과 체결(수수료 제외 원금 기준) 가능성이 확인됨.
3. 동일 종목 추가 주문 또는 타 종목 주문 시도가 발생함.
4. 승인 로그와 실제 실행 파라미터 불일치.
5. 체결/주문 API 이상, 호가 급변, 예상 슬리피지 급증 등 이상 징후 발생.

중단 직후 조치:
- 미체결 주문 전량 취소
- 상황 보고(실행자 → 전략/리스크 담당)
- 15분 내 사고 메모 작성

---

## 7) 다음 행동 확정

현재 결정이 **보류**이므로, 다음 행동은 아래로 고정한다.

1. 체크리스트 증빙 첨부(최종본 링크 + 타임스탬프) 완료.
2. 실행 대상 1종목/종목코드/지정가 산출근거 입력.
3. 1차/2차 승인권자 지정 및 승인 로그 템플릿 선기입.
4. 2인 수동 승인 완료 후에만 상태를 `승인(Go)`로 변경.

상태 변경 규칙:
- `보류 → 승인`은 1차/2차 수동 승인 서명이 모두 있어야만 가능.
- `보류 → 차단`은 정책 위반 발견 시 즉시 적용.
