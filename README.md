# 고수 종목 겹치기 실전 체크 시스템 문서화

## 프로젝트 목적
이 프로젝트의 1차 목표는 아래 2개 기준 엑셀 파일의 구조를 정확히 이해하고 문서화하는 것입니다.

- `data/raw/고수_종목겹치기_실전체크시트_샘플3일입력본_수정본.xlsx`
- `data/raw/고수_종목겹치기_실전체크시트_성향별버전_수정본.xlsx`

핵심 문서화 범위는 다음과 같습니다.

1. 실제 시트명 목록
2. 시트별 역할
3. 시트별 주요 입력 영역 / 계산 영역 / 출력 영역
4. 사용 순서
5. 직접 입력값과 자동 계산값 구분
6. 샘플 입력본과 성향별 버전 차이
7. 이후 자동화 우선순위

- `data/raw/고수_종목겹치기_실전체크시트_성향별버전_수정본.xlsx`

현재 저장소에는 `data/raw/` 디렉터리와 기준 `.xlsx` 파일이 존재하지 않습니다.
따라서 이번 커밋에서는 **실제 분석 결과를 허위로 작성하지 않고**, 다음 두 가지에 집중했습니다.

- 실제 파일이 들어오면 바로 분석할 수 있는 문서 구조 보강
- 실제 엑셀 구조를 자동 추출하는 스크립트 추가

## 구조 추출 스크립트
실제 파일이 준비되면 아래 스크립트로 시트 구조를 먼저 추출할 수 있습니다.

```bash
python3 scripts/inspect/excel_structure.py \
  data/raw/고수_종목겹치기_실전체크시트_샘플3일입력본_수정본.xlsx \
  data/raw/고수_종목겹치기_실전체크시트_성향별버전_수정본.xlsx
```

이 스크립트는 아래 정보를 출력합니다.

- 파일 존재 여부
- 시트 목록
- 시트별 사용 범위(`max_row`, `max_column`)
- 비어 있지 않은 첫 행/열과 마지막 행/열
- 표 시작 후보 위치
- 수식 셀 개수
- 값 셀 개수
- 병합 셀 범위
- 상단 샘플 행 데이터
