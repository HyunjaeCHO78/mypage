# HJ Holdings KOSPI200 적정가치 리서치부

## 1) 프로젝트 목적
본 프로젝트는 코스피200 전 종목을 대상으로 애널리스트 리포트/컨센서스 기반 목표주가(적정가치) 정보를 체계적으로 수집·정리·비교하기 위한 데이터 파이프라인의 초기 골격을 구축한다.

## 2) 핵심 목표
- 코스피200 200종목 전체에 대해 목표주가 관련 지표를 표준 컬럼으로 관리
- 최신/평균/분포(최고·최저) 기준으로 적정가치 해석
- 현재가 대비 괴리율/업사이드 산출로 저평가·고평가 후보 비교 지원
- CSV 중심 산출물로 엑셀 즉시 활용 가능하게 구성
- 향후 수급/밸류 지표(PBR, PER, ROE) 결합 확장 기반 확보

## 3) 최종 관리 컬럼 정의
- 종목코드
- 종목명
- 시장
- 섹터
- 현재가
- 최신목표가
- 1개월평균목표가
- 3개월평균목표가
- 최고목표가
- 최저목표가
- 최신투자의견
- 리포트수
- 최신리포트날짜
- 최근주요증권사
- 목표가괴리율(%)
- 업사이드(%)
- 밸류메모
- 데이터출처
- 최종업데이트일시

## 4) 운영 원칙
- 정확성 최우선(속도보다 품질 우선)
- 코드/문서는 한국어 주석·설명 중심
- 불법적 우회 접근, 과도한 비정상 수집, 차단 회피 금지
- 데이터 소스 라이선스/약관/접근 제한은 문서화 필수
- 자동수집 한계가 있으면 반자동/수동 보완 경로를 명시
- 결과물은 엑셀 친화적 CSV 구조 유지

## 5) 초기 개발 범위(1차)
- 폴더 구조 생성
- README 및 docs 초안 작성
- 코스피200 유니버스 예시(10종목) 파일 생성
- 최종 결과 템플릿 CSV 생성
- 수집/파싱/병합/계산/출력 스크립트 초안 작성
- 데이터 소스 조사 TODO 문서 작성

## 6) 향후 확장 계획
- 코스피200 200종목 유니버스 전체 확장
- 소스별 수집기 고도화(자동/반자동)
- 목표주가/투자의견/리포트 날짜 파싱 정교화
- 현재가 연계 및 품질 검증 리포트 자동화
- 기관/외국인 수급 + PBR/PER/ROE 결합 종합 점수 모델 설계

## 7) 데이터 소스 제약 사항
- 일부 포털/플랫폼은 약관/robots/로그인/요금 정책에 따라 자동화가 제한될 수 있음
- 리포트 원문/요약 데이터는 라이선스에 따라 저장·재배포 제한 가능
- 동일 종목/동일 날짜 기준이라도 소스별 수치 불일치 가능
- 자동수집이 어려운 경우 수동 근거(출처, 입력일시, 입력자 메모) 관리 필요

세부 내용은 `docs/data_source_notes.md`에 정리한다.

## 8) 자동수집/반자동/수동입력 구분 원칙
- 자동수집: 공개 접근 가능 + 구조화 데이터 + 반복 안정성이 높은 소스
- 반자동수집: 일부 수동 검증/정규화가 필요한 소스
- 수동입력: 자동화가 법적/기술적으로 어렵거나 정확성 검증이 필요한 데이터

## 빠른 시작
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/collect_reports.py
python scripts/calculate_gap.py --input output/kospi200_targetprice_table.csv --output output/kospi200_targetprice_table.csv
```

> 주의: 현재 단계의 데이터는 구조 검증용 템플릿/예시이며, 실제 투자 판단에 바로 사용하지 않는다.
