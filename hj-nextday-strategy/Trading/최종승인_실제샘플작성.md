# 최종승인 실제 샘플 작성 (실행 직전 승인 패키지 예시)

## 0) 목적 / 상태
- 목적: 실제 운영에서 바로 복붙 가능한 승인 패키지 샘플 1세트 제공
- 범위: 체크리스트 + 1차 승인 로그 + 2차 승인 로그 + 주문 후 리포트(초안)
- 현재 상태: **샘플 작성 단계 (실주문 미실행)**
- 운영 원칙: **승인 완료 전/샘플 단계에서 `test_order_enabled=false` 유지**

---

## 5) 실행 전 승인 패키지 전체 예시 (복붙용)

아래 항목을 하나의 패키지로 묶어 제출한다.

```yaml
approval_package:
  package_id: PKG-20260425-069500-001
  doc_id: FINAL-APPROVAL-20260425-069500-001
  checklist_status: PASS
  approval_status:
    l1: APPROVED
    l2: HOLD
    final_go_no_go: NO_GO
  control_flags:
    test_order_enabled: false
    live_order_sent: false
  required_evidence_links:
    checklist_url: "https://audit.internal/trading/final-approval/2026-04-25/FINAL-APPROVAL-20260425-069500-001"
    signal_snapshot_url: "https://audit.internal/trading/signals/2026-04-25/069500/snapshot-v1"
    limit_snapshot_url: "https://audit.internal/trading/limits/2026-04-25/profile-safety-v3"
    pre_live_gate_report_url: "https://audit.internal/trading/gate-reports/2026-04-25/pre-live-gate-001"
    risk_note_url: "https://audit.internal/trading/risk-notes/2026-04-25/risk-acceptance-draft-001"
    ops_briefing_note_url: "https://audit.internal/trading/ops-notes/2026-04-25/briefing-001"
  attached_records:
    - APR-20260425-069500-001-L1
    - APR-20260425-069500-001-L2
    - PTR-20260425-069500-001
  package_decision: READY_FOR_FINAL_REVIEW
```

### 패키지 판정 규칙 (샘플)
- `package_decision=READY_FOR_FINAL_REVIEW` 이면 운영책임자 최종회의 안건으로 상정
- 최종 `GO` 이벤트가 기록되기 전까지 **항상 `test_order_enabled=false` 유지**
- 본 샘플은 문서 검증용이며, **실주문 트리거로 사용 금지**
