# Trading/실매매프로젝트_읽기테스트

## 목적
- 장중(`INTRADAY_SIGNAL_BRIDGE.json`)과 장후(`INTEGRATED_SIGNAL_BOARD.json`) 신호를 실매매 프로젝트가 혼용 없이 읽는지 검증한다.
- 자동주문은 제외하고, 읽기/해석/매핑 안정성만 확인한다.

## 실행 방법
```bash
python Trading/validate_signal_delivery_formats.py
python Trading/validate_signal_read_mapping.py
```

## 검증 범위
1. phase 분리 검증
   - 장중: `market_phase=intraday`, `signal_type=temporary`
   - 장후: `market_phase=post_close`
2. 필수 필드 검증
   - `ticker`, `classification`, `score`, `priority`, `reason`
   - `generated_at`, `last_updated`
3. 타입 검증
   - 숫자: `score`, `priority`
   - 문자열: `ticker`, `classification`, `reason`
4. 샘플 개수 검증
   - 장중 샘플 2개 이상
   - 장후 샘플 1개 이상

## 실매매 프로젝트 내부 매핑 기준
- 장중(`intraday`)
  - `classification` ← `intraday_classification`
  - `score` ← `intraday_execution_score`
  - `priority` ← `execution_priority`
  - `reason` ← `priority_reason`
- 장후(`post_close`)
  - `classification` ← `final_classification`
  - `score` ← `scores.total`
  - `priority` ← `execution_priority`
  - `reason` ← `next_action`

## 통과 기준
- 필수 필드 누락 없음
- phase 충돌 없음
- 타입 불일치 없음
- 장중/장후 샘플 모두 파싱 성공
