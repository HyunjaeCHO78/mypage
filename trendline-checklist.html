HJ 추세선 거래 체크리스트 v1

이 페이지는 HJ 추세선 전략의 A+ 셋업만 선별하기 위한 실전 체크리스트 도구임. 기준서 본문을 다시 읽는 용도가 아니라, 실제 매매 직전에 구조·리스크·진입 품질을 빠르게 검증하는 데 목적이 있다.

핵심 목적

브레이크가 보여도 mediocre setup은 제거하고, 실제로 실행할 수 있는 A+ 셋업만 남긴다.

운영 방식

시장 환경 → 구조 → 브레이크 질 → 리스크 → 진입 → 보유/청산 순서로 빠짐없이 점검한다.

문서 관계

이 페이지는 실행 전 점검용이며, 기준서 본문은 별도 페이지에서 관리한다.

사용 흐름

실전 진입 전 체크리스트

먼저 필수 게이트를 통과시키고, 통과한 셋업만 100점 루브릭으로 채점해 A+ / A / B / Pass를 구분한다.

1단계

필수 게이트부터 확인

2단계

통과 시 100점 루브릭 채점

3단계

총점으로 등급 판정 후 Pass는 진입 금지

필수 게이트

점수보다 먼저 통과해야 하는 진입 금지 규칙

  • 윅만 찌른 브레이크는 진입 금지
  • 종가 기준 브레이크 확인 전 진입 금지
  • Safety line이 불명확하면 진입 금지
  • 손절 감당 불가면 진입 금지

A+는 단순 점수 합산으로 결정되지 않는다. 반드시 필수 게이트를 먼저 통과해야 하며, 총점이 높아도 게이트를 통과하지 못하면 A+로 간주하지 않는다.

사용 방법 요약
  • 1. 필수 게이트 먼저 확인
  • 2. 통과하면 각 항목 점수 계산
  • 3. 총점으로 A+ / A / B / Pass 판정
  • 4. Pass면 진입하지 않음
시장 필터

시장 환경 체크

주의 구간 먼저 제거
  • 오늘 거래 종목이 핵심 감시 종목인가
  • 뉴스/이벤트/고변동 시간대가 아닌가
  • 세션 시간대가 적절한가
  • 갭/계약전환/비정상 움직임이 없는가
  • 횡보 중심부가 아닌가
상위 구조

상위봉 구조 체크

  • 상위봉 방향이 명확한가
  • 상위봉과 정면 충돌하는 진입이 아닌가
  • 큰 수평 지지/저항이 바로 앞이 아닌가
  • 현재 위치가 추세 중간인지 극단 구간인지 확인했는가
선 구조

추세선 구조 체크

  • 유효한 추세선을 찾았는가
  • 추세선이 가격에 의해 중간 관통되지 않았는가
  • 3터치가 확인되는가
  • Point B가 최신 유효 접점인가
  • fan 구조로 더 가파른 선이 필요한지 확인했는가
  • 의미 있는 데이터 기간이 쌓였는가
브레이크 검증

브레이크 질 체크

  • 실제 브레이크가 발생했는가
  • 윅만 찌른 게 아니라 종가 기준으로 확인됐는가
  • 가능하면 break and retest가 나왔는가
  • 추세선 브레이크와 함께 수평 레벨도 확인됐는가
  • fakeout 가능성이 높은 시간대/구간은 아닌가
리스크 관리

리스크 체크

  • Safety line이 명확한가
  • 손절 위치를 진입 전에 정했는가
  • 손절까지 거리가 과도하지 않은가
  • 계좌 기준 1회 허용 손실 안에 들어오는가
  • 사이즈 축소로 저위험화 가능한가
  • 그것도 안 되면 패스할 준비가 되었는가
트리거 확인

진입 체크

  • 지금 진입이 늦은 진입은 아닌가
  • FOMO 진입이 아닌가
  • mediocre setup이 아닌가
  • 이 거래를 A+라고 말할 수 있는가
운영 계획

보유/청산 체크

  • 청산 방식이 정해졌는가
  • 추세선 붕괴 청산 / 수평 레벨 청산 / 혼합형 중 무엇인지 정했는가
  • 짧은 시간대라면 더 빠른 이익 보호 계획이 있는가
100점 루브릭

체크리스트 페이지 단독 판정을 위한 세부 점수표

구분 항목 점수
필수 점수 3터치 유효 추세선 20점
필수 점수 실제 브레이크 15점
필수 점수 Safety line 존재 15점
필수 점수 손절 감당 가능 15점
품질 점수 상위봉 정렬 10점
품질 점수 데이터 기간 충분 10점
품질 점수 종가 확인 5점
품질 점수 break and retest 5점
품질 점수 수평 레벨 동시 확인 3점
품질 점수 세션 양호 2점

종가 확인은 루브릭에서 5점으로 남아 있지만, 문서상으로는 동시에 필수 게이트다. 즉, 종가 기준 브레이크 확인이 없으면 진입 자체를 금지하고, 통과한 셋업끼리만 추가 5점 반영으로 84점과 85점 차이를 판별한다.

A+는 게이트 통과 후 85점 이상 A는 70~84점 B는 55~69점 Pass는 54점 이하
판정 구간
85점 이상

A+ · 필수 게이트를 먼저 통과한 셋업만 해당

70~84점

A · 실행 후보지만 보강 조건 확인 필요

55~69점

B · 관찰/복기 중심으로 관리

54점 이하

Pass · 진입하지 않음

84점과 85점의 차이는 A+ 여부를 가르는 기준선이다. 필수 게이트를 모두 통과한 뒤 총점이 85점 이상이면 A+, 84점이면 A로 남긴다.

패스 조건 요약
  • 뉴스·이벤트·비정상 시간대로 fakeout 가능성이 높다
  • 상위봉과 정면 충돌하거나 큰 수평 레벨이 바로 앞이다
  • 종가 기준 브레이크, Safety line, 손절 감당 가능 여부 중 하나라도 비어 있다
  • 손절이 과도하고 사이즈 축소 후에도 허용 손실을 넘는다
  • 늦은 진입, FOMO, mediocre setup 느낌이 강하다
  • 필수 게이트 통과 후 최종 점수가 54점 이하다
A+ 판정 메모
  • A+는 단순 점수 합산만으로 결정되지 않는다
  • 필수 게이트를 먼저 통과해야 한다
  • 게이트 통과 후 점수표로 A+ / A / B / Pass를 판정한다
  • 종가 확인은 진입 허용 여부를 가르는 게이트이면서, 통과 셋업 간 품질 점수 5점도 반영한다
이 페이지는 실행 전 점검용이며, 기준서 본문은 별도 페이지에서 관리한다. 실전에서는 체크리스트로 선별하고, 세부 해설과 원칙은 기존 기준서 페이지에서 참고한다.
