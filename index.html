프로젝트명 · HJ 추세선 거래 운영 기준서 v1

복잡한 시장을 단순한 추세선 Playbook으로 축소하는 운영 기준

이 기준서의 목표는 A+ 셋업만 선별하고, 손실은 작게 제한하며, 추세의 몸통을 반복적으로 회수하는 구조 기반 트레이딩 시스템을 만드는 것이다. 이후 체크리스트, 저널 양식, PineScript 설계, 백테스트 규칙, 자동화 규칙으로 확장할 수 있도록 문서 구조를 정리했다.

전략 한 줄 정의

상위 타임프레임부터 실행 타임프레임까지 유효한 추세선 구조를 연결하고, 실행봉에서 3터치 이상 확인된 추세선이 실제로 붕괴할 때 반전 방향으로 진입하되, Safety line 기준으로 리스크를 관리하고, 새 방향 추세선 또는 주요 수평 레벨을 따라 청산하는 구조 기반 A+ 추세 전환 전략.

핵심 철학

시스템이 유지해야 할 10가지 원칙

  1. 전략은 단순해야 한다.
  2. 모든 브레이크를 거래하지 않는다.
  3. A+ 셋업만 반복한다.
  4. 목표는 꼭지·바닥이 아니라 몸통 회수다.
  5. Action line과 Safety line이 진입·청산의 핵심이다.
  1. Fakeout은 없앨 수 없고 줄일 수만 있다.
  2. One strategy, one standard, one execution timeframe을 유지한다.
  3. Mediocre setup은 의도적으로 제거한다.
  4. 늦은 진입, 고위험 진입, 뉴스·비활성 시간대 진입은 패스한다.
  5. 성공의 핵심은 전략 추가가 아니라 하나의 전략을 깊게 반복하는 것이다.
핵심 용어

Action line, Safety line, Confluence를 같은 언어로 정의

Action line

가격이 실제로 돌파한 추세선으로, 진입 신호를 주는 기준선이다.

Safety line

Action line의 반대편 구조선으로, 손절·청산·리스크 관리의 기준선이다.

Three-touch trendline

최소 3개의 유효 터치포인트가 있는 추세선만 우선 사용한다.

Fakeout

브레이크처럼 보였지만 곧바로 반대로 뒤집히는 실패 돌파다.

Confluence

상위봉, 수평 레벨, 종가 확정, 리테스트, 시간대, 데이터 기간 등의 보강 요소다.

A+ setup

점수와 구조가 충분히 높고 mediocre가 아닌 우위 있는 셋업만 의미한다.

추세선 작성 규칙

최신 유효 접점과 3터치 구조를 우선하는 선만 사용

상승 추세선

  • Point A = 가장 낮은 유효 저점
  • Point B = 다음 higher low
  • 가격이 중간에 관통하면 무효

하락 추세선

  • Point A = 가장 높은 유효 고점
  • Point B = 다음 lower high
  • 가격이 중간에 관통하면 무효

공통 관리

  • Point B는 가능한 최신 유효 접점을 쓴다.
  • 이전 Point B는 다음 Point A로 이어질 수 있다.
  • Fan 구조로 더 가파른 선을 계속 갱신할 수 있다.
  • 오래전에 무효화된 선은 버린다.
  • 동일 조건이면 3터치와 긴 데이터 기간을 우선한다.
A+ Playbook

Three-Touch Trendline Break Playbook의 진입부터 청산까지

진입 조건

  1. 3터치 이상 유효 추세선
  2. 실제 브레이크 발생
  3. Safety line 존재
  4. 손절이 과도하지 않음
  5. 가능하면 1주 이상 데이터 누적
  6. 상위봉과 강하게 충돌하지 않음

방향 · 손절 · 보유 · 청산

  • 상승 추세선 하향 이탈 → 숏
  • 하락 추세선 상향 돌파 → 롱
  • 손절은 Safety line 바깥 + wiggle room 허용
  • 새 방향 추세선 유지 동안 보유, 더 가파른 선으로 trailing 가능
  • Safety line 붕괴 또는 주요 수평 레벨 도달 시 청산
브레이크 질 필터

모든 브레이크가 아니라 질 좋은 브레이크만 선별

1. 종가 확인

윅만 돌파한 경우는 무시하고, 종가가 브레이크 방향에서 마감해야 한다.

2. Break & Retest

브레이크 후 반대편에서 다시 테스트하는지 본다. 짧은 시간대일수록 중요하다.

3. 상위봉 정렬

상위 타임프레임 방향과 정렬될수록 품질이 좋아진다.

4. 수평 레벨 동시 확인

추세선과 수평 지지·저항이 함께 돌파·이탈되면 신뢰도가 높아진다.

5. 세션 필터

점심장, 비활성 시간, 이상한 시간대는 피하고 활발한 세션을 우선한다.

6. 데이터 가중치

동일한 3터치라도 1주 이상 데이터가 쌓인 구조를 더 높게 평가한다.

리스크 관리

저위험·고위험 판단과 포지션 사이징 기준

저위험 / 고위험 판단

  • 저위험: 진입가와 Safety line 거리, 포지션 크기 기준 허용 손실이 계좌 규칙 안에 들어오는 상태
  • 고위험: 구조는 있어도 손절이 멀고, 사이즈 축소 후에도 허용 손실 범위를 넘는 상태
  • 구조 좋고 가까움 → 정상 사이즈
  • 구조 좋지만 멂 → 축소 사이즈
  • 구조 나쁘고 멂 → 패스

포지션 사이징 규칙

  • 기본 1회 리스크는 계좌의 1%
  • 훈련형은 0.5~1%
  • 포지션 크기 = 허용 손실 금액 / (진입가 - 손절가)
  • A+ 셋업이어도 몰빵 금지
  • 손절 먼저 정하고 진입한다
  • 손절 감당 안 되는 사이즈는 금지
운영 체크리스트

진입 전, 보유 중, 청산 시에 반드시 확인할 것

진입 전 체크리스트

  • 상위봉 방향 확인
  • 3터치 추세선 확인
  • 실제 브레이크 확인
  • 종가 마감 확인
  • Safety line 존재
  • 손절 감당 가능
  • 늦은 진입 아님
  • 수평 레벨 확인
  • 세션/뉴스 문제 없음

보유 및 손절 규칙

  • 손절은 Safety line 바깥에 둔다.
  • 진입 전에 손절가를 확정한다.
  • 진입 후 손절을 넓히지 않는다.
  • 추세선은 trailing stop 역할을 한다.
  • 짧은 시간대는 더 빠른 이익 보호를 고려한다.

청산 규칙

  • Trendline exit: Safety line 또는 더 가파른 추세선 붕괴 시
  • Horizontal exit: 주요 수평 지지·저항 도달 시
  • 운영 종료 exit: 세션 종료, 이벤트 전, 플랫폼 규칙상 종료 필요 시
패스 & Fakeout

패스해야 할 거래를 줄이지 말고, 오히려 늘려라

패스 우선 상황

  • 손절이 너무 멀다
  • 이미 너무 늦은 자리다
  • 뉴스·갭 직전이다
  • 비활성 시간대다
  • 수평 레벨이 바로 앞이다
  • 종가 확정 전이다
  • 리테스트 없이 급히 들어가고 싶다
  • 상위봉과 강하게 충돌한다
  • Fakeout 가능성이 높다
  • A+ 점수 미달이다

Fakeout 대응 규칙

  • Fakeout은 정상 시장 행동이며 완전 제거 대상이 아니다.
  • 종가 확인, retest, 상위봉 정렬, 수평 레벨, 시간대, 데이터 기간으로 감소시킨다.
  • 발생 시 revenge trade 금지
  • 빠진 필터를 기록하고 다음 셋업을 기다린다.
  • Fakeout은 반대 방향 진짜 기회의 정보가 될 수 있다.
