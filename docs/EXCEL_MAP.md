# EXCEL_MAP

## 문서 목적
이 문서는 시트별로 **입력 영역 / 계산 영역 / 출력 영역 / 자동화 우선순위**를 한눈에 보는 요약 맵입니다.

## 실제 파일 확인 결과
기준 파일 경로:
- `data/raw/고수_종목겹치기_실전체크시트_샘플3일입력본_수정본.xlsx`
- `data/raw/고수_종목겹치기_실전체크시트_성향별버전_수정본.xlsx`

현재 위 파일이 저장소에 존재하지 않아 실제 시트별 맵은 아직 확정할 수 없습니다.

## 시트별 맵 작성 형식

### A. 샘플 입력본
| 시트명 | 주요 입력 영역 | 주요 계산 영역 | 핵심 출력 영역 | 자동화 우선순위 | 비고 |
|---|---|---|---|---|---|
| 확인 불가 | 파일 없음 | 파일 없음 | 파일 없음 | 대기 | 원본 필요 |

### B. 성향별 버전
| 시트명 | 주요 입력 영역 | 주요 계산 영역 | 핵심 출력 영역 | 자동화 우선순위 | 비고 |
|---|---|---|---|---|---|
| 확인 불가 | 파일 없음 | 파일 없음 | 파일 없음 | 대기 | 원본 필요 |

## 자동화 우선순위 판단 기준
- **상**: 매일 반복 입력하거나 반복 계산이 많은 영역
- **중**: 주기적으로 확인하지만 수작업 빈도가 조금 낮은 영역
- **하**: 참고용 요약이거나 수동 유지가 크게 부담되지 않는 영역
