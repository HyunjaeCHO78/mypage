# STOCKS_SCORING_SPEC

## 목적
이 문서는 `Stocks` 시트를 기준으로 종목 후보를 점수화하고,
보수형/공격형 프로필에 따라 **총점 계산 → 통과 여부 판단 → 상위 3개 후보 추출**까지 이어지는 구조의 초안 설계서입니다.

기준 파일:
- `data/raw/고수_종목겹치기_실전체크시트_성향별버전_수정본.xlsx`

참고 파일:
- `data/raw/고수_종목겹치기_실전체크시트_샘플3일입력본_수정본.xlsx`

---

## 1. 핵심 평가 항목
모든 항목은 기본적으로 **0~2점 원점수**를 사용합니다.
최종 총점은 `원점수 × 프로필별 가중치`의 합으로 계산합니다.

| 항목 키 | 항목명 | 정의 | 원점수 범위 | 필수 여부 |
|---|---|---|---:|---|
| catalyst_clarity | 재료 명확성 | 뉴스/공시/이슈가 분명하고 시장에서 이해되기 쉬운가 | 0~2 | 필수 |
| turnover | 거래대금 | 당일 거래대금이 충분히 붙어 있는가 | 0~2 | 필수 |
| foreign_flow | 외국인 수급 | 외국인 매수 흐름이 우호적인가 | 0~2 | 선택 |
| institutional_flow | 기관 수급 | 기관 수급이 우호적인가 | 0~2 | 선택 |
| program_flow | 프로그램 흐름 | 프로그램 매매 흐름이 긍정적인가 | 0~2 | 선택 |
| chart_setup | 차트 자리 | 돌파/눌림/지지 등의 자리가 좋은가 | 0~2 | 필수 |
| early_stage | 시세 초입성 | 이미 많이 오른 종목보다 이제 막 움직이기 시작한 구간인가 | 0~2 | 필수 |
| next_day_potential | 다음날 기대감 | 하루짜리 반응이 아니라 다음날까지 이어질 가능성이 있는가 | 0~2 | 선택 |
| market_alignment | 시장 시황과의 일치도 | 현재 시장 방향/주도 섹터와 맞는가 | 0~2 | 필수 |
| understandability | 내가 이해하는 종목인가 | 왜 가는지, 어디서 볼지 내가 설명 가능한 종목인가 | 0~2 | 필수 |

## 2. 각 항목 점수 기준 초안

### 0점
- 기준 미달
- 애매함이 큼
- 정보 부족
- 현재 진입 근거가 약함

### 1점
- 완벽하지는 않지만 최소 기준은 충족
- 확인 포인트가 남아 있음
- 보수형에서는 감점 요인이 될 수 있음

### 2점
- 매우 명확함
- 당일 전략과 잘 맞음
- 실제 후보 우선순위를 높일 수 있음

---

## 3. 총점 계산 방식

### 계산식
```text
weighted_score = Σ(각 항목 원점수 × 프로필 가중치)
```

### 계산 예시
```text
재료 명확성 2점 × 1.4
거래대금 2점 × 1.8
차트 자리 1점 × 1.3
...
```

### 통과 조건
1. 프로필의 `required_fields` 항목이 모두 입력되어 있어야 함
2. 총점이 `minimum_total_score` 이상이어야 함
3. 선택적으로 `hard_fail_rules` 같은 확장 규칙을 나중에 붙일 수 있게 구조를 열어 둠

---

## 4. 보수형 / 공격형 차이

### 보수형
- 최소 통과점이 높음
- 거래대금, 외국인/기관/프로그램 흐름, 시장 시황 일치도 비중이 큼
- 차트 자리가 애매하거나 재료가 약하면 통과가 어려움
- “안전하게 거르는 기능”에 더 가까움

### 공격형
- 최소 통과점이 더 낮음
- 시세 초입성, 다음날 기대감, 차트 자리의 비중이 큼
- 아직 완전히 증명되진 않았지만 초기 탄력이 좋아 보이는 종목을 더 살림
- 다만 재료 명확성과 거래대금은 완전히 무시하지 않음

---

## 5. 상위 후보 3개 추출 기준
1. 먼저 총점 계산
2. `minimum_total_score` 이상인 종목만 통과
3. 통과 후보를 내림차순 정렬
4. `top_n=3` 기준으로 상위 3개 선택

### 기본 정렬 우선순위
1. 총점 높은 순
2. 시장 시황과의 일치도 높은 순
3. 거래대금 점수 높은 순
4. 재료 명확성 점수 높은 순
5. 종목명 가나다순

이 정렬 기준은 프로필의 `tie_break_rules` 로 조정할 수 있습니다.

---

## 6. 동점 처리 방식
동점일 때는 아래 순서대로 비교합니다.

1. 시장 시황과의 일치도
2. 거래대금
3. 재료 명확성
4. 차트 자리
5. 종목명

필요하면 프로필별로 공격형은 `early_stage`, `next_day_potential` 을 더 앞에 둘 수 있습니다.

---

## 7. 필수 입력값 / 선택 입력값

### 필수 입력값
- `name`
- `catalyst_clarity`
- `turnover`
- `chart_setup`
- `early_stage`
- `market_alignment`
- `understandability`

### 선택 입력값
- `foreign_flow`
- `institutional_flow`
- `program_flow`
- `next_day_potential`
- 추가 메모 필드

선택 입력값이 없으면 기본값 `0점` 처리 또는 `None` 처리 후 계산 단계에서 0점으로 환산할 수 있게 설계합니다.

---

## 8. 입력 데이터 구조 초안
현재는 mock data를 사용하지만, 나중에 CSV/엑셀로 쉽게 확장할 수 있도록 아래 구조를 사용합니다.

```json
{
  "name": "종목명",
  "catalyst_clarity": 2,
  "turnover": 2,
  "foreign_flow": 1,
  "institutional_flow": 0,
  "program_flow": 1,
  "chart_setup": 2,
  "early_stage": 1,
  "next_day_potential": 2,
  "market_alignment": 2,
  "understandability": 1,
  "notes": "선택 메모"
}
```

---

## 9. 자동화 구조 제안
1. `Stocks` 시트 입력값을 JSON/CSV로 변환
2. 프로필 JSON 로드
3. 후보별 총점 계산
4. 통과 후보 필터링
5. 상위 3개 출력
6. 나중에는 결과를 다시 엑셀/리포트로 저장
