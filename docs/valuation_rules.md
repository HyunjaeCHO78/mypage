# 적정가치 해석 규칙(초안)

- 적정가치는 단일 수치가 아니라 **최신값 + 평균값 + 분포(최고/최저)** 로 해석한다.
- 애널리스트 목표가 산정 방식은 증권사마다 다를 수 있으므로 단순 비교에 주의한다.
- 리포트 수가 적은 종목은 평균값 신뢰도가 낮을 수 있다.
- 최신 목표가와 3개월 평균 목표가를 함께 비교한다.
- 리포트가 오래되었거나 적은 종목은 향후 별도 플래그(`신뢰도주의`, `데이터부족`)를 부여할 수 있게 확장한다.

## 계산 기본식
- 목표가괴리율(%) = (최신목표가 - 현재가) / 현재가 * 100
- 업사이드(%) = 기본적으로 동일 계산식 사용(정의 변경 가능성 대비 함수 분리)
