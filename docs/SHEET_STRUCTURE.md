# SHEET_STRUCTURE

## 문서 목적
이 문서는 기준 엑셀 2개의 **실제 시트 구조**를 정리하는 문서입니다.

대상 파일:
- `data/raw/고수_종목겹치기_실전체크시트_샘플3일입력본_수정본.xlsx`
- `data/raw/고수_종목겹치기_실전체크시트_성향별버전_수정본.xlsx`

## 실제 파일 확인 결과
현재 저장소에는 대상 파일 2개가 존재하지 않습니다.
그래서 아래 표는 허위 분석이 아니라, **실제 파일이 들어오면 그대로 채워 넣을 실분석 양식**으로 정리했습니다.

## 2. 실제 분석 시 시트마다 반드시 기록할 항목

### (1) 시트명
엑셀에 적힌 원본 시트명을 그대로 적습니다.

### (2) 시트 역할
예:
- 시장 체크
- 섹터 선별
- 종목 후보 정리
- 매매 계획
- 복기
- 성향별 규칙

### (3) 사용 순서
초보 사용자 기준으로 “어떤 시트를 먼저 여는가”를 숫자로 적습니다.

### (4) 주요 입력 영역
사용자가 직접 값을 넣는 칸을 적습니다.

예:
- 날짜 입력 칸
- 시장 판단 체크 영역
- 섹터 선택 영역
- 종목명 입력 영역
- 진입가 / 손절가 / 목표가 입력 영역
- 복기 메모 영역

### (5) 주요 계산 영역
수식으로 계산되는 칸을 적습니다.

예:
- 점수 합계
- 조건 충족 여부
- 손익 계산
- 누적 집계
- 성향별 판단 결과

### (6) 주요 출력/요약 영역
사용자가 최종적으로 보는 핵심 요약 구역을 적습니다.

예:
- 오늘의 매매 후보 요약
- 점수 상위 종목
- 손익 요약
- 복기 결과 요약

### (7) 표 시작 위치
실제 표가 시작되는 첫 행/첫 열을 기록합니다.

예:
- `A1`
- `B3`
- `C5`

---

## 3. 직접 입력 / 자동 계산 / 요약 영역 구분 기준

### 직접 입력 영역
사람이 판단해서 넣는 값입니다.

- 날짜
- 시장 강도 메모
- 섹터명
- 관심 종목
- 진입 계획
- 복기 메모

### 자동 계산 영역
엑셀 수식이나 스크립트가 계산하는 값입니다.

- 합계 점수
- 필터 결과
- 조건 충족 여부
- 손익 및 손익률
- 누적 성과

### 요약 영역
결과를 한눈에 보여주는 영역입니다.

- 오늘 핵심 후보
- 진입 가능 여부
- 보수형/공격형 비교 결과
- 일별 요약
- 복기 요약

---

## 4. 샘플 입력본 vs 성향별 버전 비교 기준
실제 비교는 원본을 읽고 작성해야 합니다. 분석 시에는 최소한 아래를 비교해야 합니다.

| 비교 항목 | 샘플 입력본 | 성향별 버전 | 실제 차이 메모 |
|---|---|---|---|
| 시트 개수 | 확인 불가 | 확인 불가 | 파일 필요 |
| 시장 관련 시트 | 확인 불가 | 확인 불가 | 파일 필요 |
| 보수형/공격형 분기 | 없음/확인 필요 | 확인 불가 | 파일 필요 |
| 입력 칸 수 | 확인 불가 | 확인 불가 | 파일 필요 |
| 수식 비중 | 확인 불가 | 확인 불가 | 파일 필요 |
| 복기 구조 | 확인 불가 | 확인 불가 | 파일 필요 |

---

## 5. 자동화 우선순위 제안
파일이 준비되면 아래 순서로 자동화를 추천합니다.

1. 시트 구조 자동 추출
2. 직접 입력 칸 목록화
3. 계산식 영역 분리
4. 보수형/공격형 차이 비교 자동화
5. 일일 입력 요약 및 복기 리포트 생성
