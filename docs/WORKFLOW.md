# WORKFLOW

## 문서 목적
이 문서는 실제 엑셀 파일을 사용할 때의 기본 흐름인 **시장 → 섹터 → 종목 → 매매계획 → 복기**를 설명합니다.

## 실제 파일 확인 결과
분석 대상 엑셀 2개는 현재 저장소의 `data/raw/`에 존재하지 않습니다.
그래서 이 문서는 실제 시트명 연결까지는 못 했지만, 구조가 들어오면 어떤 순서로 연결해야 하는지 기준을 먼저 정리합니다.

## 기본 사용 흐름

### 1) 시장
먼저 오늘 시장 분위기를 판단합니다.

핵심 질문:
- 오늘 적극 매매 가능한 장인가?
- 강한 방향이 있는가?
- 장 초반 변동성이 큰가?

### 2) 섹터
시장이 괜찮다면 강한 섹터를 좁힙니다.

핵심 질문:
- 어떤 테마에 거래대금이 붙는가?
- 뉴스와 수급이 같이 붙는가?
- 하루짜리 반응인지 이어질 흐름인지?

### 3) 종목
섹터가 정리되면 실제 후보 종목을 압축합니다.

핵심 질문:
- 대장주는 무엇인가?
- 후속주 중 거래가 살아 있는 종목은 무엇인가?
- 돌파/눌림/재돌파 중 어느 자리인가?

### 4) 매매계획
후보 종목이 정해지면 사전에 계획을 적습니다.

필수 항목:
- 진입 이유
- 진입가
- 손절가
- 목표가
- 비중
- 진입 보류 조건

### 5) 복기
마지막으로 실행 결과를 남깁니다.

필수 항목:
- 실제 진입 여부
- 체결가
- 계획 대비 실행 차이
- 실수 원인
- 다음 개선점

## 실제 문서화 시 연결해야 할 내용
원본 파일이 들어오면 각 단계마다 아래를 연결해 적어야 합니다.

| 흐름 단계 | 연결 시트명 | 주요 입력 영역 | 주요 계산 영역 | 핵심 출력 영역 |
|---|---|---|---|---|
| 시장 | 확인 불가 | 확인 불가 | 확인 불가 | 확인 불가 |
| 섹터 | 확인 불가 | 확인 불가 | 확인 불가 | 확인 불가 |
| 종목 | 확인 불가 | 확인 불가 | 확인 불가 | 확인 불가 |
| 매매계획 | 확인 불가 | 확인 불가 | 확인 불가 | 확인 불가 |
| 복기 | 확인 불가 | 확인 불가 | 확인 불가 | 확인 불가 |

## 보수형 / 공격형 차이 정리 기준
성향별 버전은 실제 파일을 기준으로 아래 항목을 비교해야 합니다.

- 진입 조건 수
- 필수 체크 항목 수
- 손절 기준 방식
- 목표가 운영 방식
- 비중 관리 방식
- 복기 관점 차이

현재는 원본이 없으므로 실제 차이 확정은 보류합니다.

---

## 사용자가 매일 무엇만 입력하면 되는가?
실제 자동화의 목표는 사용자의 반복 입력을 줄이는 것입니다.

원본 파일이 준비되면 아래 항목이 정확한 시트/셀 기준으로 확정되어야 합니다.

- 날짜
- 시장 판단
- 강한 섹터
- 관심 종목
- 진입가 / 손절가 / 목표가
- 실제 결과
- 복기 메모
