# INPUT_RULES

## 문서 목적
이 문서는 사용자가 직접 입력하는 값과 자동으로 계산되는 값을 구분하는 기준 문서입니다.

## 실제 파일 확인 결과
기준 엑셀 파일 2개가 현재 `data/raw/`에 없기 때문에, 이번 문서에서는 셀 주소 단위의 확정 규칙 대신 **실제 분석 시 기록해야 할 기준**을 정리합니다.

---

## 1. 직접 입력값
보통 아래 값은 사용자가 직접 판단해서 입력합니다.

### 시장 단계
- 날짜
- 시장 강도 판단
- 오늘의 매매 난이도 메모
- 특이 뉴스

### 섹터 단계
- 강한 섹터 이름
- 섹터 선택 이유
- 섹터 지속성 메모

### 종목 단계
- 관심 종목명
- 대장주 / 후속주 판단
- 종목 메모

### 매매계획 단계
- 진입 예정가
- 손절가
- 목표가
- 비중
- 진입 보류 조건

### 복기 단계
- 실제 진입 여부
- 실제 체결가
- 잘한 점
- 아쉬운 점
- 다음 개선점

---

## 2. 자동 계산값
보통 아래 값은 수식이나 스크립트로 자동 계산할 수 있습니다.

- 점수 합계
- 조건 충족 여부
- 종목 우선순위
- 손익
- 손익률
- 누적 승률
- 성향별 기준 충족 여부
- 일간/주간 요약

---

## 3. 요약 영역
요약 영역은 사용자가 최종 결과를 빠르게 보는 영역입니다.

예:
- 오늘의 핵심 종목
- 계획 대비 실행 요약
- 손익 요약
- 복기 요약
- 성향별 비교 요약

---

## 4. 실제 분석 시 정리해야 할 표 형식
실제 파일이 들어오면 아래 형식으로 시트별 입력 규칙을 작성합니다.

| 시트명 | 셀/영역 | 항목명 | 구분 | 입력 시점 | 형식 | 필수 여부 | 비고 |
|---|---|---|---|---|---|---|---|
| 확인 불가 | 확인 불가 | 확인 불가 | 직접 입력/자동 계산/요약 | 장전/장중/장후 | 텍스트/숫자/날짜/선택 | 필수/선택 | 파일 필요 |

---

## 5. 사용자가 매일 입력해야 하는 최소 항목
실제 구조가 확정되면 아래 항목을 기준으로 최소 입력 세트를 만들면 됩니다.

### 장전
- 날짜
- 시장 판단
- 핵심 섹터
- 관심 종목
- 매매 계획

### 장중
- 실제 진입 여부
- 체결가
- 계획 변경 메모

### 장후
- 결과
- 복기 메모
- 다음 날 참고사항

---

## 6. 자동화 우선순위
1. 날짜·섹터·종목 입력 보조
2. 손익/체크 결과 계산 자동화
3. 성향별 규칙 비교 자동화
4. 복기 리포트 자동 생성
5. 누적 통계 리포트 자동화
