# 데이터 소스 노트(초안)

> 본 문서는 후보 소스 조사 프레임워크이며, 실제 적용 전 라이선스/약관/접근 제한 검토가 필수다.

## 1) 자동수집 가능 후보

### 예: 공식 API/계약형 데이터 피드
- 소스명: 유료 데이터 API(예: 벤더 계약형)
- 데이터: 목표주가, 컨센서스, 투자의견, 리포트 메타데이터
- 목표주가 제공 여부: 가능(계약 범위 의존)
- 투자의견 제공 여부: 가능
- 리포트 날짜 제공 여부: 가능
- 증권사 정보 제공 여부: 가능/부분 가능
- 이용 제한/주의사항: 유료 라이선스, 재배포 제한, 호출량 제한
- 자동화 난이도: 중
- 향후 적용 우선순위: 높음(정합성/안정성 우수 시)

## 2) 반자동수집 필요 후보

### 예: 증권사 리서치 페이지(웹)
- 소스명: 국내 증권사 리서치 센터 웹페이지
- 데이터: 리포트 제목, 날짜, 의견, 목표가(문서 내 표기)
- 목표주가 제공 여부: 있음(종목별/리포트별 편차)
- 투자의견 제공 여부: 있음
- 리포트 날짜 제공 여부: 있음
- 증권사 정보 제공 여부: 있음
- 이용 제한/주의사항: robots/약관/접근 정책 준수, 구조 변경 잦음
- 자동화 난이도: 중~상
- 향후 적용 우선순위: 중상

### 예: 포털 컨센서스 페이지
- 소스명: 포털 금융 컨센서스
- 데이터: 평균 목표가, 투자의견 요약, 리포트 수
- 목표주가 제공 여부: 있음(요약치 중심)
- 투자의견 제공 여부: 있음
- 리포트 날짜 제공 여부: 일부 제공
- 증권사 정보 제공 여부: 제한적
- 이용 제한/주의사항: 화면 파싱 안정성/약관 확인 필요
- 자동화 난이도: 중
- 향후 적용 우선순위: 중

## 3) 수동입력 필요 후보

### 예: PDF 리포트 직접 검토
- 소스명: 애널리스트 리포트 PDF(수동 검토)
- 데이터: 목표가, 의견, 날짜, 증권사, 근거 메모
- 목표주가 제공 여부: 있음
- 투자의견 제공 여부: 있음
- 리포트 날짜 제공 여부: 있음
- 증권사 정보 제공 여부: 있음
- 이용 제한/주의사항: 저작권/이용허락 범위 확인 필요
- 자동화 난이도: 상(실질적으로 수동)
- 향후 적용 우선순위: 높음(품질 보완 핵심)
