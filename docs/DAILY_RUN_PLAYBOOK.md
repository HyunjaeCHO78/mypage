# DAILY_RUN_PLAYBOOK

## 목적
이 문서는 사용자가 매일 최소 입력만 하고,
보수형 기준으로 후보 종목 상위 3개를 빠르게 확인할 수 있도록 만든 일일 운영 가이드입니다.

핵심 원칙:
- 하루 후보는 최대 5~10개만 입력
- 기본은 `conservative`
- 공격형은 비교용 또는 예외 상황에서만 사용
- 상위 3개만 검토
- 나머지는 과감히 버림
- 결과가 나와도 최종 진입 판단은 사용자가 한다

---

## 매일 사용자 할 일 5단계
1. 오늘 볼 후보 종목을 5~10개 안으로 압축합니다.
2. `templates/candidate_input_template.csv` 에 종목과 점수를 입력/수정합니다.
3. 아래 기본 실행 명령어를 1번 실행합니다.
4. 콘솔에 나온 상위 3개 후보를 확인합니다.
5. `reports/` 폴더의 결과 파일과 요약 파일을 보고 최종 매매 후보를 정리합니다.

---

## CSV 템플릿 수정 방법
기본 입력 파일은 아래입니다.

- `templates/candidate_input_template.csv`

수정 방법:
1. 기존 예시 행을 오늘 후보 종목으로 바꿉니다.
2. 한 줄에 한 종목만 입력합니다.
3. 점수 항목은 모두 `0`, `1`, `2` 중 하나로 적습니다.
4. 하루 후보는 **최대 5~10개만** 유지합니다.
5. 필요 없는 예시 행은 삭제합니다.

주요 컬럼:
- `ticker`
- `name`
- `theme`
- `material_clarity`
- `trading_value`
- `foreign_flow`
- `institutional_flow`
- `program_flow`
- `chart_position`
- `early_stage`
- `next_day_expectation`
- `market_alignment`
- `understanding`

---

## 기본 실행 명령어
실전 기본 실행은 아래 한 줄만 사용합니다.

```bash
python3 scripts/run_daily_conservative.py
```

이 명령은 아래를 자동으로 수행합니다.
- `templates/candidate_input_template.csv` 읽기
- `conservative` 프로필 고정 사용
- 내부적으로 `scripts/run_candidate_pipeline.py` 호출
- 결과 JSON 저장
- 요약 텍스트 저장
- 콘솔에 최종 후보 3개 표시

---

## 결과 파일 확인 방법
실행 후 기본적으로 아래 파일을 확인하면 됩니다.

- `reports/candidates_conservative_top3.json`
- `reports/daily_conservative_summary.txt`

확인 포인트:
1. 상위 3개 종목명
2. 총점
3. 주요 점수 상세
4. 통과 여부
5. 경고가 있는지 여부

## 실수했을 때 복구 방법

### 1) CSV를 잘못 수정했을 때
- 가장 쉬운 방법은 `templates/candidate_input_template.csv` 를 다시 열어서 헤더를 확인하고 수정합니다.
- 행 하나가 꼬였으면 그 행만 다시 입력합니다.

### 2) 점수를 잘못 넣었을 때
- `0`, `1`, `2` 외 값이 들어가면 경고가 나올 수 있습니다.
- 잘못 넣은 셀만 수정하고 다시 실행하면 됩니다.

### 3) 종목을 너무 많이 넣었을 때
- 상위 후보 비교가 흐려집니다.
- 5~10개 이내로 줄이고 다시 실행합니다.

### 4) 결과가 마음에 안 들 때
- 바로 공격형으로 바꾸기 전에,
  먼저 보수형 점수 입력이 맞는지 다시 확인합니다.
- 시장 시황 일치도, 거래대금, 재료 명확성 점수가 과대/과소평가되지 않았는지 봅니다.

### 5) 실행 실패 시
- CSV 파일 경로가 맞는지 확인
- 헤더 이름이 템플릿과 같은지 확인
- 숫자 칸에 문자 입력이 없는지 확인
- 실패 메시지를 보고 수정 후 다시 실행

## 공격형은 언제만 쓰는가?
공격형은 기본 모드가 아닙니다.
아래 같은 경우에만 비교용으로 사용합니다.

- 장이 매우 강하고 추세가 분명할 때
- 초입 종목을 더 빠르게 잡아야 할 때
- 보수형 결과 외에 추가 관찰 후보를 보고 싶을 때
- 예외적으로 탄력 장세에서 비교 기준이 필요할 때

즉, **공격형은 기본 실행이 아니라 보조 비교용**입니다.

---

## 처음 20거래일은 왜 보수형만 써야 하는가?
처음 20거래일은 시스템 적응 기간으로 보는 것이 좋습니다.

이 기간에 보수형만 쓰는 이유:
1. 입력 습관을 먼저 안정화해야 함
2. 점수 기준을 일관되게 익혀야 함
3. 공격형까지 동시에 쓰면 기준이 흔들리기 쉬움
4. 상위 3개만 보는 습관을 먼저 만들어야 함
5. 결과를 복기하면서 어떤 점수 항목을 내가 과대평가하는지 확인할 수 있음

즉, 처음에는 **정확도와 일관성**이 중요하고,
그 다음에야 공격형 비교가 의미가 있습니다.
